# Acader 📚

**Your AI-powered study companion.**

Acader transforms your existing study materials into an interactive learning experience. Upload your notes, PDFs, or other class materials and generate personalized practice tests, flashcards, and study notes in seconds.

🌐 **Website:** [acader.co](https://acader.co)

## ✨ Features

- 📝 **AI-Generated Tests** — Create practice tests from your study materials with customizable question counts and difficulty levels.
- 🗂️ **Flashcards** — Generate flashcards to reinforce key concepts and improve retention.
- 📖 **Study Notes** — Turn your materials into organized, easy-to-review notes.
- 📊 **Progress Tracking** — Save and review your study materials and test results.
- 🔐 **User Accounts** — Sign up and log in to access your study workspace.

## 🛠️ Tech Stack

- **Language:** Python
- **Frontend:** Streamlit
- **AI:** LangChain and OpenRouter
- **Authentication & Database:** Supabase

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   cd Acader
   ```

2. Create and activate a virtual environment:

   ```bash
   python -m venv venv
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure your environment variables for your AI provider and Supabase credentials.

5. Run the application:

   ```bash
   streamlit run app.py
   ```

## 🎯 Mission

Acader aims to make studying more personalized, interactive, and accessible by helping students turn their own learning materials into effective study tools.
